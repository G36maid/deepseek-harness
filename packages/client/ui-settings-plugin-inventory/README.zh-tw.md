# @deepseek-ai/dsh-client-ui-settings-plugin-inventory

[English](README.md) | [简体中文](README.zh.md) | 繁體中文

Web 設定中的只讀**外掛程式清單**分頁標籤。瀏覽器外掛程式註冊一個 id 為 `all` 的本機化 `settings.plugins.tab` 貢獻；“外掛程式”分區擁有導覽入口與標籤欄。外掛程式激活期間不會讀取 Remote；首次選擇該分頁標籤時才掛載元件，並透過 [`api-remotes`](../../api/remotes/README.md) 懶呼叫 `ctx.remote.pluginInventory.list()`。

該分頁標籤以可搜尋的雙列緊湊摺疊卡片展示清單。每張收起的卡片使用模組短名稱作為標題，以小標籤表示有效啟停狀態；已啟用的條目還會以彩色圓點表示根 fiber 狀態。展開卡片後會直接展示 Loader 樹條目 id，不附加重複的欄位標題，並列出有效設定狀態；已啟用的條目還會列出 Cordis 狀態，已停用的條目則省略重複的“未掛載”執行狀態。條目 id 仍作為 React key、展開標識、詳情值與額外的搜尋目標；程式碼不按字串形狀對它分類。載入、空結果、無匹配結果與通用失敗狀態只屬於已掛載元件；讀取失敗後可以重試，且不會暴露傳輸細節。註冊使用 `ctx.slots.inject()`，因此能跟隨標籤 slot 的延遲聲明、重新聲明、本機化變化與 teardown，而無需 import 分區擁有方。

## 模型體驗

無，因為本包只在瀏覽器設定中展示 Host 擁有的部署快照，不註冊任何模型介面。

#### KV Cache 影響

無；本包既不組裝也不傳送提供方請求。

## 已知限制與暫緩事項

- **每次 Settings 掛載或重試只讀取一份快照** —— 分頁標籤不訂閱 Loader 變化，也不會在重連後自動重新讀取；切換分頁標籤會保留當前快照，重新打開 Settings 則會取得新快照。
- **只讀 Loader 檢視表** —— 本機搜尋不會額外引入來源、按來源分組、當前瀏覽器啟用診斷或外掛程式修改控制元件。
