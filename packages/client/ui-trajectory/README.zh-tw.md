# @deepseek-ai/dsh-client-ui-trajectory

[English](README.md) | [简体中文](README.zh.md) | 繁體中文

Trajectory 算繪按輪次組織的事件記錄表，其中選填擇使用者、助手、工具和巢狀子工具記錄。較粗的分隔線標示輪次邊界，緊湊的行內標記標識步驟，主記錄表僅保留索引、事件和內容；選擇記錄則會打開區域性檢查器，查看 token 用量、耗時、輸入、輸出和計時。可捲動的概述區域預設保持捲軸滑桿透明，直到滑鼠懸停該區域或其中包含鍵盤焦點時才顯示，同時不改變捲軸預留的幾何空間。獨立執行的壓縮（compaction）請求會按時間順序顯示在自己的 `Between turns` 區段中，而帶編號的壓縮仍位於其所屬輪次內。長記錄表打開時定位於當前尾部，使用者到達已載入範圍頂部時載入一頁更早的歷史，並且只掛載可見行視窗和少量額外緩衝行；僅含請求的分隔行並入下一個具備可測高度的虛擬項，語義行鍵和 ARIA 索引在向前補頁後保持不變。選擇、時間線導覽、摺疊、搜尋和請求彙總只覆蓋當前已載入的視窗。初始尾部完成定位前，記錄表會用明確的載入行遮住真實記錄。更早的前綴仍未載入時，已載入記錄前會始終保留首行控制元件；單擊它會載入一頁更早的歷史，頁面載入期間則會原地變為停用的載入狀態。固定在記錄表上方的 Overview 區域從左到右投影記錄的真實開始時間與耗時；仍有更早記錄未載入且 viewport 包含已載入時間域起點時，中性的省略號控制元件會標識被省略的前綴，並可載入一頁更早歷史，而不會為未知部分虛構耗時。助手時間條會區分記錄到的 TTFT 與解碼時間，懸停 500 ms 後可查看精確時刻和耗時詳情。拖選一個區間會將記錄表聚焦到活動區間與該閉區間有重疊的所有記錄，清除選擇則復原完整的已載入記錄表。滾輪手勢用於縮放時間域。右鍵單擊會清除所選區間；在已放大的 viewport 上按住右鍵拖動則只會平移檢視表，不會改變該區間。初始檢視表和流式更新都會停留在尾部；向上捲動會暫停跟隨，因此新記錄不會打斷對舊記錄的檢查。僅含內容更新的流式幀會保持虛擬行的鍵和高度不變、複用測量結果，並且不會重複寫入末尾捲動位置。已完成的回覆會在 Trajectory target State 中保留組裝後的 blocks、計時與用量，共享 Session 視窗則保留原始 Event。Trajectory 要求工作階段殼將 composer 作為浮層置於全高記錄表上方；其響應式縱向捲動容器會預留 composer 的即時高度，確保仍可捲動到最後幾行。Trajectory 自有的 Definition 從共享 Session 視窗組裝業務記錄，其中包括因取消而凍結的助手和工具記錄，因此 Trajectory 既不讀取也不改變 Chat 工作階段快照。該包不提供 service，也不聲明 Context 合併；它會註冊 target 專屬 Event Definition、Trajectory view builder，以及工作階段 `'conversation.view'` slot 環中的一個檢視表分頁標籤。約定：api-contracts v3 §8。

## 模型體驗

無。軌跡檢視表在瀏覽器中算繪工作階段資料；這裡沒有任何內容進入模型請求。

#### KV Cache 影響

無；該包既不組裝也不傳送提供方請求。

## 已知限制與暫緩事項

- **進行中時，Time 保持空白**：`partial` 與 `runningCalls` 行會顯示執行狀態，但不會虛構耗時，因此 Overview 區域只算繪開始標記，而不會杜撰即時跨度。記錄選擇與時間線選擇位於 Trajectory 內部，不提供錨點深連結。
