# dsh-client-ui-settings-plugins

[English](README.md) | 繁體中文

**外掛程式**設定分區及其**外掛程式設定**分頁標籤。該分區擁有標題與緊湊的標籤欄；功能外掛程式透過 `settings.plugins.tab` 貢獻頁面。本包自己的分頁標籤為每個設定由使用者擁有的 Host 外掛程式展示一張可展開卡片。卡片展示外掛程式名稱及其管轄範圍；就地展開後是綁定到該外掛程式 settings 命名空間的手寫控制元件，每個欄位標注使用者是否覆蓋過它，並提供重設回部署組裝值的入口。

## 這裡會出現什麼

只有當某個命名空間既被存活的 Host 外掛程式註冊、又被服務給瀏覽器時，它的卡片才會渲染。未組裝該外掛程式的部署——或未向任何用戶端服務該命名空間的部署——不會渲染空卡片或停用卡片，而是什麼都不渲染，因此“外掛程式設定”分頁標籤反映的是該部署實際執行的東西。

第一批覆蓋 shell 執行器（`bash`）、agent 迴圈的工具呼叫平行度（`agent-loop`）以及 DeepSeek 搜尋提供方（`web-search-deepseek`）。

## 擴充點

本分區聲明根級清單 slot `settings.plugins.tab`，其標籤會成為有序分頁標籤。某個分頁標籤首次被選擇後會保持掛載，因此本機草稿與只讀快照在切換分頁標籤時不會丟失。本包註冊自己的 `configurable` 貢獻，由它聲明巢狀的 `settings.plugin.item` 清單 slot。帶瀏覽器半側的外掛程式把自己的卡片註冊進這個巢狀 slot 並擁有其控制元件；本包既不枚舉命名空間，也不渲染未被交給它的表單。兩層排序都遵循貢獻的 `order`。

## 寫入

卡片暫存使用者輸入，只有使用者保存時才寫入。每個控制元件渲染的都是暫存文字，因此螢幕上所見即保存後所存；**放棄修改**丟棄這些草稿，持有未保存修改的卡片即使收起也會在標題上標明。重設暫存的是組裝預設值而非立即寫入；欄位不接受的草稿會阻塞保存，而不是被丟棄。

保存時，每個暫存欄位都透過用戶端 settings scope 寫入，該 scope 用讀取時的命名空間 revision 為每次寫入設柵，因此已與文件脫節的表單會被拒絕，而不是覆蓋並行變更。某個值是否被接受只有 Host 說了算——schema 表達不了的約束歸它的校驗器所有——因此卡片在寫入後回讀分節，報告沒有落盤的保存，並保留這些草稿供使用者修改。

金鑰也可能從別的表層寫入——模型頁尋址的是同一個引用——而那不改變任何 settings 分節，因此卡片會在轉發來的 `credentials/updated` 事件報告它所關注的引用時重讀。

欄位是否被覆蓋，取決於它是否出現在原始使用者層中，而非取決於它的值；重設會清除該欄位，使其重新繼承組裝層。secret 角色的欄位絕不搭乘回應，因此金鑰控制元件初始為空、只報告是否已設定，並經由 credentials 領域而非 settings 分節寫入；空草稿不寫入任何東西，保留已存金鑰。

## 模型體驗

無。該分區渲染瀏覽器設定 UI；它寫入的值只透過擁有這些值的外掛程式到達模型，而這些效應各由其擁有方的包記錄。

#### KV Cache 影響

無；該包既不組裝也不傳送提供方請求。

## 已知限制與暫緩事項

- **只有宿主平面的外掛程式會出現**——由 agent preset 掛載的外掛程式把設定內聯在該 preset 的 `agent.cordis.yml` 中，且根本無法註冊 settings 命名空間（同一 preset 掛載第二個工作階段時會因重複註冊而失敗），因此本分區不會列出它。編輯那些值仍是 preset 編輯器的職責。
- **暴露是 Host 的白名單，而非外掛程式的聲明**——不在 api-proxy 白名單中的命名空間，即便其擁有方已註冊，也只會得到 `settings-not-exposed`，因此在本倉庫之外分發的外掛程式無法在不改動 `packages/host/apiproxy` 的前提下讓自己的設定出現在這裡。
- **shell 卡片跟隨被組裝的執行器**——POSIX 與 PowerShell 兩個執行器家族共用 `bash` 命名空間，因為一個宿主只組裝其中之一，所以被服務的 schema 隨平臺不同（PowerShell 多出 `pwshPath`），儘管卡片在兩者下編輯的都是同樣兩個欄位；而兩者都不組裝的部署不會顯示這張卡片。
- **空態數的是已註冊卡片，不是可見卡片**——命名空間未被本部署暴露的卡片什麼都不渲染，但仍計入數量，因此一個都不暴露的部署看到的是空清單而非那行空態文案。該計數還只讀取一次，因為渲染器會快取根級 entry 的 inject face；之後註冊的卡片不會讓它變大。
