# @deepseek-ai/dsh-fs-e2b

[English](README.md) | [简体中文](README.zh.md) | 繁體中文

[`@deepseek-ai/dsh-fs`](../../fs/fs/README.md) 提供方約定的 E2B 實作。它沒有設定：先載入 [`@deepseek-ai/dsh-e2b`](../e2b/README.md)，再用本服務取代 `dsh-fs-local`。該提供方使用所有者的遠端 cwd 和 SDK 控制代碼，因此文件工具觀察到的環境與 E2B 後端 Bash 行程相同。

## 行為

- **遠端身份與元資料**：相對路徑以呼叫方 cwd 或 `ctx.e2b.cwd` 為基準，按照 POSIX 路徑解析；GNU `realpath -mz` 提供規範化目標身份，且不要求最終文件存在；ASCII/base64 加嚴格 NUL 分幀會在已解碼的 SDK 傳輸中保留含換行符和多位元組字元的路徑。`stat`、不跟隨連結的 `lstat` 和穩定的單層目錄清單會把 E2B 元資料投影到檔案系統 seam；目錄清單會複用已返回的元資料，並依次解析符號連結條目。版本是 E2B 元資料與每次寫入設定的擴充屬性所組成的不透明雜湊。
- **執行環境路徑**：規範化目標公開絕對 POSIX 行程路徑、百分號編碼的 `file:` URI，以及由提供方負責的包含關係檢查，因此通用子行程消費端無需解析 E2B 目標 ID，也不會套用宿主路徑規則。
- **UTF-8 讀取**：完整讀取和流式讀取會保持跨區塊解碼的連續性、拒絕無效 UTF-8，並使用 seam 的 8192 位元組 NUL 樣本偵測二進位內容。面向模型的工具仍負責選擇大小和行視窗。
- **有界原始位元組讀取**：`readBytes` 在任何內容傳輸之前先按 stat 大小短路，然後流式讀取遠端對象，並在第一個超過 `maxBytes` 的區塊處取消流（`FS_TOO_LARGE`），因此靜態超限文件和 stat 後成長的文件都不會被完整緩衝進宿主記憶體。所釘版本 SDK 的空文件怪癖（content-length 為 0 時 stream 格式返回 `''`）產生空結果。
- **原子變更**：寫入會建立隨機的同級暫存目錄，在上傳內容前將其 mode 改為 `0700`，並保留現有文件的 POSIX mode。替換操作透過 E2B 的同一檔案系統原子重新命名發布。帶防護的 `createIfAbsent` 改用遠端 `ln -T` 發布，即使目標位置出現目錄，也能使提交具備原子且不替換的語義；系統會把提交前從暫存文件讀取的元資料投影到目標路徑，以生成返回的版本，因此任何一類提交點之後都不會再進行可能失敗的元資料請求。E2B 會建立缺失的父目錄。字面量編輯匹配時會規範化為 LF，儲存時復原佔主導的 CRLF，並在宿主行程內按規範化目標序列執行變更。
- **失敗與取消**：E2B 的未找到、權限、中止及其他控制器故障會對映到現有 `FsError` 詞彙。取消在更早的 SDK 請求邊界上採用盡力而為語義，並在發布前立即檢查。訊號不會傳入 rename 或防護連結提交，因此取消無法中斷原子發布，也不會把已提交的寫入報告為失敗。

該提供方不會複製、掛載或協調宿主工作區。把宿主路徑用作 `cwd`，只會在遠端建立一個拼寫相同的目錄。

## 模型體驗

透過 [`dsh-tool-fs`](../../fs/tool-fs/README.md) 間接影響模型；該工具會渲染遠端 UTF-8 內容、目錄結果、變更確認和提供方錯誤，而 E2B 身份及傳輸保持內部實作。

#### KV Cache 影響

不會直接失效；請求前綴變更由具名消費端負責。

## 已知限制與延後工作

- **不提供宿主同步**：空的 E2B cwd 會一直為空，直到工具、命令或外部行程填充它；本機文件既不會上傳，也不會同步回本機。
- **變更協調僅限宿主行程內**：`createIfAbsent` 會保留與發布發生競態的遠端建立者所寫入的文件，但另一個 harness 連線或命令仍可能與替換操作發生競態；版本防護只能偵測 E2B 元資料所體現的變更。
- **讀取會按路徑重新打開規範化目標**：在解析與打開流之間若並行替換遠端路徑，該操作沒有穩定文件控制代碼提供圍欄；在該 POC 中，沒有已觀察到的產品缺陷能夠證明提供方專用的有界讀取協議值得引入。
- **仍需承擔完整文件變更成本**：覆蓋差異和字面量編輯會把完整文件讀入宿主記憶體，每項操作也都會產生 E2B 控制器延遲。
- **該 POC 面向 E2B 默認 Linux 映像檔**：它相依性 GNU `realpath`／`base64`／`chmod`、同一檔案系統內的 rename、流式讀取和元資料擴充屬性；自訂範本不在該 POC 範圍內。
