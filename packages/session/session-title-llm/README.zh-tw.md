# @deepseek-ai/dsh-session-title-llm

[English](README.md) | [简体中文](README.zh.md) | 繁體中文

由模型支援的工作階段標題提供方的共享實作策略。它解析輔助路由，將精確選中的使用者訊息封裝為 JSON，記錄可分發的確切請求，應用語言感知的標題指令，強制執行輸入和輸出預算，組合逾時與呼叫方取消，組裝流，並返回規範化文字，同時給出確切來源 seq 以及生成該文字時使用的提供方／模型路由。

此包是普通庫，不是 Cordis 外掛程式。提供方外掛程式呼叫 `registerSessionTitleLlmProvider()`，傳入各自節奏與訊息選擇器；該函式驗證共享設定，並將每次修訂委派給 `generateSessionTitleWithLlm()`，使各外掛程式的註冊、路由、提示詞、取消與驗證行為不會漂移。

## 路由與失敗約定

`provider` 和 `model` 覆蓋項都是選填的，但必須同時作為非空字串提供。如果沒有這一對取值，輔助模組會使用當前工作階段已記錄 `request/header` 中捕獲的確切提供方／模型路由；因此，在任何路由出現前顯式刷新時必須提供覆蓋項。輔助模組在記錄或分發前，依據 `maxInputBytes` 檢查最終 JSON 封裝使用者提示詞的大小，包括 seq 欄位、包裝層與 JSON 轉義，而不是將其截斷。消費流期間和流完成後都會重新檢查逾時與呼叫方取消，因此即使攔截器或配接器忽略 abort，也不能接受遲到的成功結果。格式錯誤或空輸出、工具呼叫和非 stop 結束原因同樣會導致呼叫被拒絕；工作階段標題服務決定該拒絕屬於自動警告還是顯式呼叫方失敗。

路由與輸入驗證完成後，輔助模組會在模型分發前直接透過 `Session` 追加僅寫入日誌的 `session/title-llm-request` 事件。它包含標題提供方 id、確切來源 seq、路由、系統提示詞、訊息清單，以及該呼叫使用的輸出 token 上限。持久化會立即觀察到該記錄；追加不需要標題專屬標記、類型斷言、結帳佇列或刷寫。分發的請求封套會深度凍結，攜帶 `purpose: 'session-title'`，且有意不包含 dsh-agent-loop 的行程本機請求身份。攔截器會與記錄保持一致，而迴圈專用重建觀察者不會把它與對話請求標頭比較。DeepSeek 配接器會根據該用途停用思考，使少量輸出預算全部用於可見標題文字；其他配接器負責自身用途專用行為。後續模型失敗會保留請求記錄；從未成為可分發請求的驗證失敗不會建立記錄。該事件始終位於派生模型歷史之外。

## 設定

除成對的路由覆蓋項外，每個欄位都必填；庫不提供預設值。

| 鍵 | 約定 |
|---|---|
| `targetWords` | 非 CJK 標題的正整數目標詞數。 |
| `targetCjkCharacters` | 中文、日文或韓文標題的正整數目標字元數。 |
| `maxInputBytes` | 最終 JSON 封裝使用者提示詞的正整數 UTF-8 位元組上限。 |
| `maxOutputTokens` | 輔助生成的正整數 token 上限。 |
| `timeoutMs` | 執行時期定時器限制內的正數端到端時限。 |
| `provider`, `model` | 選填顯式路由；二者同時提供或同時省略。 |

## 模型體驗

### 輔助標題請求

#### 模型看到的內容

標題模型會收到固定系統指令，要求以輸入語言返回一個簡潔且無裝飾的標題；該指令包含所設定的詞數與 CJK 字元數目標。它唯一的使用者訊息包含一個 JSON 陣列，其中是精確選中的使用者訊息及其 seq。

#### Token 影響

輔助請求根據所選輸入大小和 `maxOutputTokens` 消耗 token。它與主 agent（代理）請求相互獨立，不會向 agent 歷史增加標題文字或封裝內容。DeepSeek 標題呼叫會關閉思考；主對話保留自身設定的思考模式。

#### KV Cache 影響

不會使主請求的 KV Cache 失效。輔助快取複用由提供方決定；固定指令可複用，而 JSON 訊息陣列會隨每次修訂變化。

## 已知限制與暫緩事項

- 輔助模組只接受文字輸出，並拒絕工具呼叫；不公開結構化輸出配接器或提供方專用提示詞變體。
- 它對整個封裝使用者提示詞強制執行位元組上限，不會剪裁單則訊息或應用保留策略。
