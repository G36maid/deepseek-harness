# Agent Note: 移除 TUI 包

Status: implemented

[English](2026-08-04-remove-tui-package.md) | [简体中文](2026-08-04-remove-tui-package.zh.md) | 繁體中文

## 問題

移除隱式的 `dsh` 終端機應用後，`@deepseek-ai/dsh-tui` 不再擁有任何已交付的組合。該包仍包含終端機渲染器、互動式命令與問答配接器、擴充浮層、快照 fixture（測試前置資料）、已打修補程式的 `pi-tui` 相依性，以及仍將 TUI 宣稱為受支持應用介面的 SDK 腳手架。保留這整套能力意味著繼續維護一個產品規模的前端，而其唯一剩餘消費端就是項目生成器本身。

該包還會使倉庫所支持的應用清單產生誤導。當前可執行產品使用 Web、ACP（Agent Client Protocol）、JSON-RPC 或一次性 CLI（命令列介面）入口，SDK 卻仍提供終端機選項，而沒有任何示例或產品命令會實際使用它。

## 決策

刪除 `packages/ui/tui` 包，不提供相容包或別名。其原始碼、包測試、終端機快照、相依性聲明、已打修補程式的 `pi-tui` 產物、workspace 引用、生成的服務目錄條目和文件會一並移除。通用宿主能力與 agent loop（代理循環）能力保持不變。

作為 TUI 包最後消費端的 SDK 項目工具鏈已由[工具鏈移除決策](2026-08-11-remove-sdk-project-toolchain.md)刪除。宿主應用仍可直接掛載提供方無關的 `dsh-user-questions`、`dsh-commands` 和呈現服務。

本決策取代[顯式設定 `dsh` 入口決策](../../archived/simplification/2026-08-03-explicit-config-dsh-entrypoint.md)中保留可複用包的決定，也使已歸檔 TUI 實作記錄不再適用於當前狀態。這些歷史記錄繼續保持凍結，但不再作為受支持包或應用清單的依據。

本記錄彙總了因移除該包而無法繼續保持現行有效、現已刪除的僅涉及該包的記錄。終端機 UI 曾在長對話期間保持工作階段身份可見、移除重複模型標籤、為訊息附加耗時與階段狀態、在提示詞旁顯示 workspace 與分支上下文，並保守地解析完整 XML 包裝層，以生成人類可讀的回退輸出。這些選擇改善了一個終端機前端，但在沒有部署的情況下，並不足以證明應保留它。未來的 XML 回退仍必須使用真正的解析器而非正規表達式。

## 驗證

倉庫搜尋結果與生成的服務目錄中不再包含 TUI 包、相依性修補程式、服務鍵或包連結。常規原始碼建置、型別檢查、lint、hygiene、文件閘門以及其餘組裝快照測試套件均可在沒有已刪除 workspace 的情況下執行。

## 考慮過的替代方案

**保留未交付的包。** 不予採納，因為這會保留維護成本，並繼續將一個沒有真實組合證明其生命週期的、不受支持的終端機前端呈現為可複用的產品介面。

**為外部消費端保留 SDK 選項。** 不予採納，因為生成器會成為該包在倉庫內唯一的消費端，並會搭建一個倉庫不再進行端到端驗收的應用。預發布相容性立場不要求保留該選項。

**將包移入 examples 或 experimental 組。** 不予採納，因為移動程式碼無法提供當前產品需求、受維護的部署或組裝驗收。未來的終端機前端應以其實際宿主和互動需求為起點，而不是默認繼承此實作。

## 後果

DeepSeek Harness 不再提供終端機 UI 包。現有 import 和相依性該包的 `cordis.yml` 條目會直接失敗，不會得到相容轉換。Web 仍是已交付的互動介面；ACP、JSON-RPC 與一次性 CLI 仍是 Web 之外的入口。

提供方無關的命令、使用者互動、審批、工具呈現、PTY 與工作階段投影能力仍可供其他宿主使用。重新引入終端機前端時，必須為其提供具名產品或部署、顯式包邊界、具體互動提供方，以及組裝後的生命週期與 transcript（文字記錄）驗收。
