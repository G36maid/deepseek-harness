# Agent Note: 本機 JSON 樹渲染器

Status: implemented

[English](2026-07-28-local-json-tree-renderer.md) | [简体中文](2026-07-28-local-json-tree-renderer.zh.md) | 繁體中文

## 問題

[軌跡檢查記錄表](../feature/2026-07-27-trajectory-inspection-ledger.md)使用的只讀 JSON 檢查器需要提供緊湊的對象和陣列預覽、供複製操作使用的明確陣列路徑、固定展開與可摺疊兩種根節點模式，以及鍵盤導覽。`react-json-view-lite` 既不提供自訂節點渲染，也不提供行標識；要透過該相依性滿足這些要求，就必須使用套件管理員為編譯後的發布文件打修補程式，並遍歷 DOM，從可見標籤中還原資料路徑。該修補程式實際上相當於一個不受類型約束的 fork，但其原始碼對映與上游原始碼均未同步修改。

## 決策

`dsh-client-ui-primitives` 中的 `JsonTree` 自行負責遞迴呈現。

- 每個渲染行都直接接收自身的值和屬性路徑。遞迴時，對象鍵和陣列索引會附加到路徑末尾，因此複製操作無需再從 DOM 渲染文字中反向還原應用資料。
- 可展開行在本機渲染緊湊預覽，僅在展開時掛載子行。`expandTopLevel` 選填擇固定展開的括號框架或可摺疊根節點，而不改變元件的公開約定。
- 樹中所有可見節點僅保留一個可透過 Tab 鍵聚焦的展開控制元件。使用指針啟用控制元件後，該控制元件會成為 Tab 鍵焦點位置；上、下方向鍵迴圈移動焦點，左、右方向鍵摺疊或展開當前焦點所在節點。
- `react-json-view-lite` 不在 `dsh-client-ui-primitives` 的相依套件中，也沒有 pnpm 修補程式。針對性元件測試鎖定預覽、展開、鍵盤焦點和陣列複製路徑。

## 曾考慮的替代方案

**保留發布文件修補程式。** 不予採納：應用專用的渲染邏輯和陣列標識約定仍會隱藏在生成的第三方文件中；每次更新相依套件，都必須評審一個沒有配套原始碼對映的 fork。

**直接使用不提供預覽的上游渲染器。** 不予採納：`{…}` 和 `[…]` 會丟失軌跡檢查器掃讀時所需的緊湊載荷上下文。

**渲染後注入預覽和行元資料。** 不予採納：Effect 或 MutationObserver 仍會相依性同一套私有 DOM 結構，同時使 React 和命令式變更機制分別負責同一行的不同部分。

**採用更大型的 JSON 查看器。** 不予採納：編輯、搜尋與主題系統不在當前只讀約定範圍內；擴大相依性範圍也無法去除檢查器專用的複製和版面配置程式碼。

## 後果

JSON 檢查器在原始碼層由單一實作負責，具有顯式資料流和準確的陣列路徑，且沒有經過修補程式修改的相依性。`dsh-client-ui-primitives` 負責遞迴渲染、展開狀態、ARIA 樹結構和焦點迴圈移動行為，因此修改這些語義時必須提供針對性元件測試。實作有意保持只讀，僅包含當前消費端使用的預覽、導覽與複製行為。
