# Agent Note: 不相依性具體能力的沙盒策略上下文

Status: implemented

[English](2026-07-31-capability-neutral-sandbox-policy-context.md) | 繁體中文

## 問題

當前策略上下文最初透過受強制執行家族與可升權家族兩個獨立登錄檔來對映執行時期組合。後端、工具與示例中的六個呼叫點會貢獻 `filesystem`、`bash` 或 `terminal`；策略服務保留 token 集合，以便獨立釋放各項註冊，對兩個登錄檔的內容求交集並排序，在每次生命週期變化時使提示詞組裝失效，並且需要測試覆蓋所有家族組合。

這份清單既不是說明文件策略所必需的，也不能作為模型可見能力的權威依據。後端貢獻可能聲明某個家族，而該家族面向模型的工具並不存在，或被請求作用域隱藏；工具 schema 已經向模型準確說明哪些操作可用。因此，為了維護一句近似的英文說明，登錄檔擴大了公開服務與生命週期約定。

## 決策

`dsh-sandbox-policy` 為每個 agent（代理）工作階段貢獻一項不相依性具體能力的 `sandbox:policy` 上下文。上下文文字只根據 `resolve({ session })` 派生；不存在後端或工具家族註冊 API、貢獻對映、排序規則，也不會因註冊變化而使提示詞失效。

該文字將能力聲明限定於 DSH 文件沙盒所強制執行的可用操作。在 `read-only` 下，它說明這類操作在常駐模式下無法修改文件，並指示模型正常嘗試可用工具，隨後遵循該工具返回的任何拒絕與升權引導。在 `workspace-write` 下，它說明規範化的工作階段工作區，以及帶有適用條件的臨時區域寫入許可。在 `danger-full-access` 下，它說明 DSH 文件沙盒不會限制可用操作修改文件。

哪些操作可用仍以工具 schema 為準。針對具體操作的拒絕以及獲批後的更寬鬆模式重試，仍以工具結果為準。檔案系統、一次性 bash 與終端機實作繼續解析並強制執行相同的逐呼叫策略；移除的只有面向模型的冗餘能力清單。

本決策取代了[當前沙盒策略上下文決策](../feature/2026-07-30-current-sandbox-policy-context.md)中關於家族註冊與按組合條件化措辭的部分內容。快取安全的上下文交付、持久快照物化、措辭證據，以及引導與強制執行之間的邊界，仍以該 Agent Note 為歸屬文件。

## 曾考慮的替代方案

**保留登錄檔，但減少對應測試。** 不予採用，因為公開方法、保留的生命週期狀態、六個貢獻點和近似的能力聲明仍會存在。組合測試只是體現了這一設計成本，並非成本的成因。

**從工具登錄檔派生確切清單。** 不予採用，因為當前策略只需要一句符合事實的條件性聲明，而確切的可用情況已經體現在組裝後的工具 schema 中，並且可能隨請求作用域變化。若再把每個 schema 對映回其強制執行後端，就會引入另一項派生關係，而當前沒有消費端需要它。

**僅在後端聲明會強制執行時提供策略上下文。** 不予採用，因為這會重現註冊問題，並使策略是否可見取決於選填貢獻方。即使沒有可適用的操作，這段帶條件的措辭仍然符合事實。

## 後果

策略服務只有一條由歸屬方直接派生的上下文路徑，無需維護兩個公開登錄檔及其釋放生命週期。增加或移除能力不再導致執行時期上下文快照反覆變化，模式和工作區變化仍會觸發快照更新。聚焦測試仍覆蓋各模式的確切措辭、規範化根目錄、模式切換、復原、服務釋放與無 agent 組裝；家族組合與貢獻生命週期測試則隨其所保護的行為一同刪除。

模型不再收到以自然語言列出的沙盒能力家族清單，而是收到確切的工具 schema 與一項常駐文件策略聲明。未來若產品需要獨立的能力清單，該清單必須從權威的逐請求組裝結果中派生，不能透過後端註冊這種旁路機制重建。
