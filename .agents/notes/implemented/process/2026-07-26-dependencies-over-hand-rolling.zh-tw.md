# Agent Note: 優先選用持續維護的相依性，而非手寫實作

Status: implemented

[English](2026-07-26-dependencies-over-hand-rolling.md) | [简体中文](2026-07-26-dependencies-over-hand-rolling.zh.md) | 繁體中文

## 問題

harness 手寫了大量基礎設施，而成熟的外部包早已提供同等能力。其中一部分是有意為之——以原始碼形式收錄的 Cordis（[引入 vendor 的決策](2026-06-11-vendor-cordis-as-source.md)）、[孿生 LLM（大型語言模型）配接器](../architecture/2026-06-13-twin-llm-adapters.md)、作為設定 schema 標準的 schemastery——但相當大一部分是在一種未經言明的「避免新相依性」下意識作用下逐漸累積而成的：倉庫級的外部相依性清單始終很小，各包卻各自長出了自己的 SSE（Server-Sent Events）解析器、協議分幀器、重試迴圈和 glob 匹配器。`AGENTS.md` 其實從未寫下任何相依性政策，agent（代理）只能從既有模式中自行推斷出一條，而這條推斷出的規則（「不要加相依性」）比任何人實際決定過的都更嚴格。這正是 Not Invented Here（非我發明）謬誤在默認狀態下運作：每一個對維護良好的庫的手寫克隆，都是要由我們自己測試、撰寫文件、評審和除錯的程式碼，卻享受不到生態累積下來的邊界情況修復。

## 決策

引入外部相依性是一種正當的簡化，而不是政策特例。當一個維護良好的包（或我們引擎下限即已提供的 Node 內建能力）覆蓋了某塊手寫介面面時，替換手寫程式碼就是優先方向，並遵循與其他任何簡化相同的證據標準：這次替換必須切實縮減我們負責維護的內容（程式碼、測試和約定面），而不是僅僅把複雜度挪到一個包裝層後面。

新相依性的准入門檻：

- **淨刪除。** 該相依性替換的是實際由我們維護的程式碼（實作 + 專屬測試 + 文件），而不是假想中的未來程式碼。只增加能力的相依性屬於功能決策，不屬於簡化。
- **健康度。** 持續維護、廣泛使用、傳遞相依性足跡合理。一個無人維護的小包，只是拿我們的程式碼換來別人廢棄的程式碼。
- **邊界契合。** 該包的語義要覆蓋我們的實際約定；仍需圍繞它手寫補齊的殘留語義，要計入這次替換的減分項。
- **不觸碰已定案的 seam。** schemastery（設定 schema）、原始碼收錄的 Cordis、`@earendil-works` 孿生配接器，以及其他記錄在已實作 Agent Note 中的決策，不因本政策而重開；一次會瓦解已記錄設計的替換，必須勝過所記錄的論證理由，而不能只援引本 Agent Note。

`packages/util/` 的「零相依性」章程描述的是該分組的*匯出*紀律（util 包不攜帶 harness 相依性，從而任何分組都能相依性它們），並不禁止在能帶來簡化時使用外部包；如果一個 util 包的全部職責有維護良好的外部包做得更好，就應當用該相依性替換它，而不是為了章程而保留它。

相依性替換提案與其他任何移除類提案一樣，記錄為 `proposed/simplification` Agent Note，寫明候選包、可刪除的介面面、殘留語義和供應鏈考量。本政策會使相依性清單成長，這份清單的安全公告掃描與更新節奏由[供應鏈提案](../../proposed/process/2026-06-11-supply-chain-and-vendor-drift.md)負責。

## 曾考慮的替代方案

- **維持隱性的「不加新相依性」文化。** 不予採納：它從來不是一項有記錄的決策，而其成本是具體的——手寫的協議與解析程式碼重複實作了久經實戰檢驗的庫，推高了按文件計的覆蓋率負擔，還拖慢每一位評審人：他們必須重新推導生態早已修復的邊界情況。
- **一份獲批包的硬性白名單。** 不予採納：倉庫處於預發布階段，相依性集合很小；按 PR（Pull Request）設定證據門檻（淨刪除、健康度、契合度）再加評審，就能把判斷留在上下文所在之處，無需一份本身也需要維護的常設委員會式產物。
- **像 Cordis 一樣把每個新相依性都以原始碼形式收錄。** 不予採納：原始碼收錄（vendor）只適用於我們必須打修補程式、或必須鎖定以抵禦上游變動的包（[引入 vendor 的決策](2026-06-11-vendor-cordis-as-source.md)）；將其推廣到所有相依性，會重新製造出引入相依性本要卸下的維護負擔。默認做法是普通 NPM 相依性加 lockfile 鎖定。

## 後果

- 巡查簡化機會的 agent 與貢獻者，現在把「用包 Y 替換手寫的 X」視為範圍內的產出；[dsh-find-simplifications](../../../skills/dsh-find-simplifications/SKILL.md) 承載相應指引。
- 相依性清單會成長，供應連結觸面隨之擴大；緩解措施記錄在[供應鏈提案](../../proposed/process/2026-06-11-supply-chain-and-vendor-drift.md)中，本政策使該提案更加緊迫。
- 根 `AGENTS.md` 承載一行規則；論證理由與准入門檻由本 Agent Note 持有。
