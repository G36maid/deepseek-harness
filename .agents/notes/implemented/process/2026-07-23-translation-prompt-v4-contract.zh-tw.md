# Agent Note: 經校準的翻譯提示詞 v4 約定

Status: implemented

[English](2026-07-23-translation-prompt-v4-contract.md) | [简体中文](2026-07-23-translation-prompt-v4-contract.zh.md) | 繁體中文

## 問題

自動生成對側檔案需要一份穩定的提示詞，能夠復現經人工評審的譯文所確立的語體和修正方式。注入通用說明文件，會讓這份經校準的模型輸入隨著面向人類或 agent（代理）的指導發生變化，而未經封裝的回應無法分別承載草稿、自檢內容和修正後的文件。普通的類 XML 分段標籤還會與用於說明這些標籤的合法 Markdown 內容發生衝突。

## 決策

提交入庫的[翻譯提示詞](../../../../docs/i18n/translation-prompt.md)是經過校準的管線資源。其渲染器僅注入源語言、目標語言和當前[術語表](../../../../docs/i18n/terminology.md)，並在組裝請求前拒絕未知、缺失或文法格式錯誤的佔位符。請求組裝器在模型可見的提示詞之外保留原始檔基本名，並在真正的源文件之前，將每組經評審的整篇文件對編排為一個純文字 user/assistant 示例輪次。範本可以包含針對特定模型的校準規則，但這些規則必須服從倉庫的配對、術語、結構與強調格式約定。

v7 校準保留這套 v4 協議，並明確指令優先級：先保持源文含義與受保護結構，再遵循術語表，然後以整篇金標校準語體，最後應用一般指導與內嵌示例。模型先以母語技術作者的方式起草，再逐分句對照源文，保留執行主體、條件、否定、情態、生命週期條件、方向、結果通道、所有權和數量。文體指導不得虛構執行主體，也不得僅為豐富措辭而改換術語表詞形、已定義概念或約定動詞。無法裁定的術語在譯文中保持不變，只在評審段報告為待評審項。

回應包含三個有序的頂層分段：`translation`、`review` 和 `final`。回應消費端根據保留的原始檔上下文推導目標文件基本名，保留文件開頭選填的 YAML frontmatter，並以機械方式在 `final` 中第一個 H1 之後插入或校正語言切換列。解析器要求每個分段恰好出現一次，拒絕封套之外的內容，並允許回應最外層有一層 `xml` Markdown 圍欄，因為模型有時會照抄提示詞中的示例圍欄。

## 回應封裝格式

分段定界行由協定格式（wire format）保留。當 Markdown 正文中的某一行僅包含定界標籤（前面可以帶反斜槓）時，序列化器和模型會在行首再新增一個反斜槓；解析器則只移除一個。這種保留計數的轉義方式讓字面量定界標籤與已轉義的定界標籤都能無損往返，同時不會改動行內提及的標籤。

可執行約定由[渲染器、請求組裝器、解析器和回應消費端](../../../../scripts/translation-prompt.ts)實作。單元測試覆蓋兩個翻譯方向、請求順序、佔位符校驗、目標路徑校驗、嚴格的分段順序與數量約束、帶圍欄的回應、行內提及標籤、Markdown 正文中的定界行，以及保留 YAML frontmatter 的新配對語言切換列校正。一個無金鑰子行程快照鎖定組裝後的提示詞、五個經評審的示例輪次，以及帶 YAML frontmatter 的錄制回應經目標路徑校正後的消費結果。

## 考慮過的替代方案

**在每個請求中注入 `translation-rules.md`。** 該文件既約束人類與 agent，也約束自動翻譯管線。注入它會讓編輯規範的每次澄清都與模型行為耦合，並擠佔經過人工校準的提示詞約束；因此管線僅注入具約束力的術語表，並直接校驗自身資源。

**使用嚴格的 CDATA XML 文件。** CDATA 提供通用的 XML 封裝，但會引入一層巢狀協議、額外的 `]]>` 轉義規則，以及三段式約定原本不需要的 XML 解析器行為。預留並轉義六種定界行，既能維持經校準的回應分段，也能保留任意 Markdown 內容不變。

**只返回最終譯文。** 單一正文更易解析，卻會丟棄顯式修正步驟；這個步驟用於在發布前發現語氣、結構、術語和標點缺陷。

**用較新的實驗提示詞整體替換經校準的 v4 資源。** 後續實驗澄清了一些有價值的通用規則，但作為完整替代方案未透過嚴格的整篇文件評估。生產資源只吸收能夠保留既有示例與可執行協議的改進。

**要求嚴格的草稿到定稿變更帳本。** 要求定稿中的每項修改都出現在自由文字評審帳本中，會增加輸出負擔，卻不能證明評審能夠發現區域性語義漂移。評審段記錄實際修正，定稿仍需接受確定性結構檢查與人工評審。

## 影響

提示詞措辭屬於可執行行為，因此需要經過程式碼評審、翻譯提示詞校驗器校驗及可執行的請求/回應快照驗證。聚焦測試固定內嵌示例與選定的 v7 保護規則。`translation-prompt-v4` 快照目錄命名的是穩定的渲染器／解析器協議系列，而不是當前校準修訂號。經校準的資源與通用翻譯規則可以針對各自的受眾分別演進，但評審必須拒絕任何與倉庫約定衝突的改動。只有當源文件中的封裝標籤獨佔一行時，行轉義才會顯現；解析器測試鎖定這一無損行為。
