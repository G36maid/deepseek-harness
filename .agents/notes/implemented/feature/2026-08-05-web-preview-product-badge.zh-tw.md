# Agent Note: Web 預覽版產品徽標

Status: implemented

[English](2026-08-05-web-preview-product-badge.md) | [简体中文](2026-08-05-web-preview-product-badge.zh.md) | 繁體中文

## 問題

Web 空狀態沒有標明產品處於預覽版階段。使用者可以在未看到產品尚未正式發布的情況下進入主工作階段介面；若改用部署設定，則會把面向整個產品的生命週期決策誤表述為操作者的選擇。

## 決策

空狀態主視覺區始終在標題下方渲染本機化的 `Preview` / `预览版` 徽標。它沒有設定開關：預覽狀態是所有部署共同的一項產品身份，而不是隨部署變化的可調參數。

徽標沿用 business-tertiary 背景，使兩套主題都保留產品藍的視覺語境；文字則使用主題的 primary label token。這一組合讓普通 12px 文字在淺色與暗色主題下都有足夠的對比度。business-primary 前景色僅留給較大字級文字或非文字強調元素，因為它在該背景上達不到要求的對比度。

首個 tagged release 取消倉庫的預發布立場時，或歸屬產品方明確決定預覽階段結束時，產品會移除該徽標。這一改動會同時移除徽標及其 locale key，而不是增加執行時期開關。

## 曾考慮的替代方案

**讓預覽狀態可設定。** 不予採納：同一個預發布產品的兩套部署不得展示不同的生命週期身份，設定欄位還會把產品發布狀態變成一項不受支持的操作者選擇。

**在 business-tertiary 背景上使用 business-primary 文字。** 不予採納：由此產生的淺色與暗色主題對比度低於徽標 12px 文字所要求的 4.5:1。

**在無障礙樹中隱藏徽標。** 不予採納：預覽狀態是產品資訊而非裝飾，因此無障礙標題會包含徽標文字。

## 後果

每個新工作階段都會在視覺與無障礙輸出中呈現相同的本機化預覽版身份。移除預覽狀態是一項顯式的產品發布改動；徽標保留業務藍色調背景，同時採用可讀的中性色文字，而不是全藍色處理方案。

## 測試

工作階段元件測試覆蓋兩個本機化徽標值，Web 生命週期快照則固定組裝後空狀態主視覺區中的英文徽標。
