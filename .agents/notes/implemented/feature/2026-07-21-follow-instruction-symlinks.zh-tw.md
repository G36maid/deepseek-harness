# Agent Note: 跟隨符號連結指向的指令文件

Status: implemented

[English](2026-07-21-follow-instruction-symlinks.md) | [简体中文](2026-07-21-follow-instruction-symlinks.zh.md) | 繁體中文

## 問題

[agent-instructions 外掛程式](2026-06-24-workspace-context.md)在解析前用 `ctx.fs.lstat` 探測每個指令候選，拒絕任何末段的符號連結，從而使倉庫自有的連結無法把指令載入指向工作區之外的內容。這條「不跟隨」不變式擋住了一個有意為之、且受支持的設定：使用者若把 `$DSH_HOME/AGENTS.md`（或某個項目的 `AGENTS.md`）符號連結到別處保存的一個規範指令文件，以便在多個工具與多個 home 之間共享同一份規範文件，就會看到該連結被悄悄忽略。它還迫使內容去重把無處不在的 `CLAUDE.md → AGENTS.md` 映像檔當作一個被跳過的特例來處理，而非一個普通的重複文件。倉庫所有者要求在每個 scope 上無條件跟隨符號連結指向的指令文件，並接受下文記錄的殘餘信任邊界風險。

## 決策

指令發現不再用 `lstat` 檢查末段。每個候選（使用者全域性的 `$DSH_HOME/AGENTS.md`、每個基礎候選，以及每個本機覆蓋候選）都會被解析，並對其解析後的目標做 stat，基線組合時與每一輪 `tools/post-execute` 協調時一視同仁。一個目標為常規文件的符號連結會載入該目標的內容；一個解析後的非文件目標（包括指向目錄的連結）是被確認的缺失，會像缺失文件一樣移除該 scope；一個 `resolve` 或 `stat` 例外被歸類為暫時不可用，且從不移除已載入的 scope。`nodeStatFile` 呼叫 `stat`（宿主路徑），`fsStatFile` 先 `resolve` 再 `stat`（提供方路徑）；兩者都不呼叫 `lstat`。

一個被跟隨的符號連結對下游每一步都是普通文件。它參與按目錄的內容去重（[載入全部並去重說明](2026-07-21-instruction-load-all-dedup.md)），因此一個符號連結指向其同級 `AGENTS.md` 的 `CLAUDE.md` 現在會解析到相同內容，並像任何逐位元組相同的真實副本一樣被合併，而不再作為特例被跳過。

### 信任邊界與殘餘風險

跟隨倉庫自有的連結會越過外掛程式的信任邊界：一個被克隆的、不受信任的倉庫可以攜帶一個 `AGENTS.md`，其符號連結目標是該行程能讀取的任意文件，從而把樹外內容作為工作區指導暴露出來。該內容僅作為一條被 system-reminder 模式框定、權威性較低的 user 角色前綴進入；它絕不覆蓋 system、developer 或使用者的直接指令，並被當作資料而非權威依據。起緩解作用的邊界在檔案系統層，而非本外掛程式：在部署載入不受信任的倉庫時，用 `dsh-fs-observation-policy` 防護機制或一個作業系統沙盒（[跨家族 fs 沙盒](2026-07-14-cross-family-fs-sandbox.md)）約束 `ctx.fs`。這是一個明確的、由所有者接受的取捨，而非疏漏。

## 備選方案

**保留 `lstat` 的「不跟隨」不變式。** 被倉庫所有者否決：它擋住了受支持的「符號連結到規範文件」設定，並迫使符號連結映像檔場景成為一個被跳過的特例而非普通重複。它所近似的讀取權限邊界屬於檔案系統策略與沙盒層，那裡能更精確地遏制同一風險。

**只跟隨使用者全域性的 `$DSH_HOME` 候選，項目文件保持不跟隨。** 否決：所有者要求在每個 scope 上行為一致，而一條分裂的規則比一條一致應用的策略加一條有文件記錄的邊界更難推理。使用者選擇打開的項目並不比使用者自己的 home 更值得信任。

**跟隨符號連結，但拒絕解析到項目根之外的目標。** 否決：這會在錯誤的層（路徑幾何而非讀取權限）重新引入一條區域性的信任邊界，破壞合理的「`$DSH_HOME` 指向別處」場景，並重複檔案系統策略門已經擁有的遏制。

## 後果

一個符號連結指向的指令文件現在會像其目標一樣被載入和渲染，從而支持在多個工具與多個 home 之間共享規範指令文件，而 `CLAUDE.md → AGENTS.md` 映像檔會透過內容去重而非被跳過。指令載入不再相依性 `ctx.fs.lstat`；一個解析後的非文件是被確認的缺失，只有提供方例外才是暫時不可用。信任邊界從本外掛程式移出，進入檔案系統策略與沙盒層。當部署載入不受信任的倉庫時，它們必須約束 `ctx.fs`。[agent-instructions note](2026-06-24-workspace-context.md) 與包 README 承載相同的跟隨行為與殘餘風險聲明。
