# Agent Note: 外掛程式自有的人類命令註冊

Status: implemented

[English](2026-07-19-plugin-command-registration.md) | [简体中文](2026-07-19-plugin-command-registration.zh.md) | 繁體中文

## 問題

TUI 擁有斜槓命令。如果命令名、幫助文字、自動補全、分派和取消都留在配接器內部，每個新命令都需要修改 TUI，選填外掛程式也無法貢獻命令。把斜槓輸入當作普通模型提示詞同樣不安全：使用者可見的直接操作可能意外消耗 token，或讓模型重新解釋未知命令。

共享機制必須仍是 UI 關注點，而不是模型工具或 agent loop（代理循環）分支。它還需要精確到每個 agent（代理）的可見性、HMR（熱模組替換）安全移除、直接結果渲染和請求作用域取消，同時不會自動把命令文字或輸出加入模型歷史。

## 決策

位於 `packages/interaction/commands/` 的 `@deepseek-ai/dsh-commands` 是產品命令登錄檔。TUI 應用組合包把它掛載在消費該服務的前端旁；[僅面向自動化的 ACP（Agent Client Protocol）應用](../simplification/2026-07-23-acp-automation-only-protocol.md)和無執行器、無 UI 的 agent spine 都省略該服務。TUI 注入該服務，命令生產者只相依性登錄檔及其操作的領域。

### 登錄檔約定

`CommandDefinition` 包含不帶 `/` 的小寫名稱、非空描述、選填的非結構化輸入提示，以及可取消處理器。註冊會校驗元資料並複製一份與呼叫方脫離的副本、凍結最終生效的定義，並返回對應 Cordis effect 的精確 disposer（資源釋放器）。同一層中的重複名稱會失敗。每個消費端都能看到所有有效定義；若命令外掛程式無法在某種部署中執行，它就不在該部署中註冊，而不是把消費端身份編碼進共享領域。

`list(agent)` 在作用域遮蔽後返回不可變、按名稱排序的描述符。`find(agent, name)` 解析有效定義。`execute(agent, line, signal)` 解析並執行已知定義，返回分離後的 `success` 或 `error` 結果；無效文法和未知名稱返回 `undefined`，由配接器負責生成直接展示的錯誤文字。

`parseCommand(line)` 要求 `/` 位於第零位元組，後接由字母、數字、`_` 或 `-` 組成的小寫 ASCII 名稱，並以空白或輸入末尾結束。它把配接器交付的完整後綴保留為 `rawInput`，包括分隔空白。每個命令外掛程式自行負責後續所有文法決策。

### 作用域與生命週期

無作用域註冊是全域性註冊。掛載在 agent 上下文之下並注入 `commands` 的外掛程式會繼承該 agent 的作用域鍵與生命週期，因此其定義只會為對應的同一個 agent 遮蔽同名全域性定義。子外掛程式自行聲明 `commands` 注入，因為 `agent.ctx` 有意繼承核心 agent loop 的相依性介面；僅為了實作作用域註冊而讓迴圈相依性 UI 服務會倒置相依性圖。

註冊和移除會發出未過濾、不可否決的 `commands/change` 登錄檔通知。配接器重新計算每個存續 agent 的有效檢視表，而不嘗試推斷某次變更影響哪些工作階段。登錄檔會分別隔離並記錄每個觀察者失敗，因此損壞的 UI 刷新無法回滾另一外掛程式的變更，也無法阻止後續觀察者。Cordis 所有權會在生產者、UI 實例或 agent 作用域解除安裝時移除定義，因此 HMR 不會留下過時的發現項或處理器。

### 直接分派與取消

命令在僅面向人類的命令平面中執行。登錄檔不會把輸入轉成 `user/message`，輸出不會成為工作階段事件，兩者都不會隱式傳送給模型。處理器接收對應的同一個目標 agent、原始輸入和本次請求持有的 `AbortSignal`；生產者可以透過該 agent 顯式調度單獨的模型可見工作，隨後由生產者負責其日誌記錄和生命週期約定。訊號中止時，登錄檔不再等待不合作的處理器；處理器仍負責停止已經啟動的外部副作用。

預期的處理器失敗返回 `CommandResult.error`。拋出的例外或格式錯誤的結果仍是配接器可見的命令失敗，而不是模型訊息。該邊界有意分離 UI 輸出與持久領域變更：例如目標命令可以改變 `ctx.goals`，但持久狀態由目標服務擁有。

### TUI 對映

TUI 把內建斜槓命令註冊為 agent 作用域命令定義，不再對字串執行 switch。自動補全與幫助檢視表讀取即時目錄，因此外掛程式命令會隨其 effect 出現和消失。任何以 `/` 開頭的提交行都留在命令平面；未知輸入產生終端機警告，不會落入 `Agent.steer()`。

每次提交命令都會建立一個專屬 `AbortController`。TUI 釋放會中止未完成的分派、移除本機定義，並等待命令生產者的 fiber 結束後再完成清理。

## 測試

登錄檔測試覆蓋文法邊界、不可變規範化、執行時期元資料校驗、確定性排序、全域性與作用域遮蔽、重複拒絕、準確釋放、變更通知失敗隔離、直接呼叫、預期和格式錯誤結果、同步與非同步失敗，以及每種中止時序邊沿；達到逐文件 100% 語句、分支、函式和行覆蓋率。

TUI 測試覆蓋全部遷移後的內建命令、即時外掛程式發現、幫助與自動補全刷新、直接結果、未知命令拒絕、原始輸入交付、定義移除、啟動回滾和釋放取消。無金鑰終端機快照固定渲染後的幫助、錯誤與命令結果形態。

## 考慮過的替代方案

- **保留配接器本機 switch**——不予採納，因為選填外掛程式無法貢獻發現與行為，除非修改 TUI。
- **把人類命令表示為模型工具**——不予採納，因為發現與直接呼叫屬於人類 UI 行為；經由模型路由會增加延遲、token 成本和重新解釋。
- **把登錄檔放入核心 agent spine**——不予採納，因為無 UI 執行入口不消費它，而 TUI 可以顯式組合它。
- **讓 `dsh-agent-loop` 注入 commands**——不予採納，因為迴圈不執行也不發現人類命令。agent 作用域生產者改為在子外掛程式中聲明 UI 相依性。
- **為每個定義附加配接器掩碼**——不予採納，因為支持能力是組合事實，而不是命令領域狀態。每個已組合配接器都暴露已註冊命令；不相容外掛程式不會在該部署中註冊。
- **把未知斜槓輸入傳送給模型**——不予採納，因為輸入錯誤或不可用的直接操作必須可預測地失敗，而不能改變執行平面。
- **持久化通用命令輸入與輸出**——不予採納，因為配接器提示不是模型可見狀態。改變持久行為的處理器會呼叫擁有該狀態的領域 API，由後者記錄自己的事件。

## 後果

- 命令生產者是普通的可移除外掛程式，TUI 消費其經過校驗的目錄與分派約定。
- 特定於 agent 的定義保留現有扁平作用域與遮蔽語義，不引入核心到 UI 的相依性。
- 未知斜槓輸入與命令輸出是確定性 UI 行為，直接模型 token 成本為零。
- 直接命令取消與模型輪次取消彼此隔離。

## 已知限制與暫緩事項

- 輸入元資料僅限非結構化文字提示。類型化表單、參數 schema 和補全提供方仍由命令擁有，或需要後續登錄檔或消費端擴充。
- 通用命令輸出僅即時存在，TUI 重新啟動後不會重建。
- 登錄檔取消會立即停止等待，但外部工作只有在處理器配合訊號時才會停止。
- ACP 自動化伺服器、無頭 CLI（命令列介面）與 JSON-RPC SDK 執行入口不暴露命令平面；只有 TUI 消費它。
